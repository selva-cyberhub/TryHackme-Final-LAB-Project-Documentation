# TryHackMe Final Lab Project Documentation

Study guides and lab writeups completed as part of the Cybersecurity Domain course at Ironhack Institute. Each document covers the full attack chain for a TryHackMe room: reconnaissance, exploitation, privilege escalation, and remediation, with screenshots and reasoning for each step.

## Contents

### CTF_Ironhackable_documentation_final.pdf
Lab: **Ironhackable**
Attack path: web shell upload -> reverse shell -> PTY stabilization -> privilege escalation via a GTFOBins technique (zip). Covers the full exploitation chain with flag-by-flag breakdowns and reasoning for each command used.

### CTF_Ironhole_Study_Guide_Final.pdf
Lab: **Ironhole**
Attack path: credential-based initial access (FTP password cracked via Hydra) -> direct SSH login (no exploit chain needed for privilege escalation, since sudo was already configured ALL:ALL). Includes a comparison against the Ironhackable room's attack path, plus a combined interview-angle section covering both rooms.

### THM_lab_Hackers_Hideout_StudyGuide_final.pdf
Lab: **Hackers Hideout**
Study guide covering reconnaissance, exploitation, and privilege escalation steps for this room, documented in the same structured format as the other two.

## About this documentation
These are personal study guides, written to reinforce hands-on lab work and to be usable as interview-prep reference material — not official TryHackMe or Ironhack content. More labs will be added here as they're completed.
